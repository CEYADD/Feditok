# Accessibility (a11y) & WCAG Audit: SettingsScreen

**Target Scope**: `lib/screens/home/profile/settings_screen.dart` (`SettingsScreen`, `_DeleteConfirmDialog`)  
**File Path**: `d:\Feditok\lib\screens\home\profile\settings_screen.dart`  
**WCAG Standard**: WCAG 2.1 / 2.2 Level AA  
**Platform Guidelines**: Android (48x48 dp), iOS (44x44 dp)

---

## Executive Summary

`SettingsScreen` organizes preferences and critical account actions into four sections: Accesso (Email/Password updates, disabled for ActivityPub users), Privacy (Server video lifecycle), Memoria (Local backup management), and Danger Zone (Logout, Data takeout request, Permanent account deletion with a 5-second safety timer). Key accessibility defects include lack of live region updates during the account deletion countdown lockout and missing heading semantics across settings sections.

---

## Findings by Severity

### 1. High Severity

#### [HIGH-01] Missing Live Region on Safety Countdown Lockout in Delete Confirmation Dialog
- **File**: `d:\Feditok\lib\screens\home\profile\settings_screen.dart`
- **Line(s)**: 326–341, 378–392
- **WCAG Guideline**: WCAG 4.1.3 Status Messages (Level AA), WCAG 2.2.1 Timing Adjustable (Level A)
- **Defect**: In `_DeleteConfirmDialog`, the confirm button is disabled for 5 seconds (`_secondsRemaining`), updating the button text each second from `5s` down to `0s`. However, because the button is disabled and there is no `Semantics(liveRegion: true)` or announcement:
  1. Screen reader users are not informed of the countdown duration.
  2. Assistive tech users receive no notification when the lockout expires and the button becomes clickable.
- **Code Fix**:
```dart
// Add an accessible announcement or wrap the countdown text in a live region:
Semantics(
  container: true,
  liveRegion: true,
  child: ElevatedButton(
    style: ElevatedButton.styleFrom(
      backgroundColor: Colors.redAccent,
      foregroundColor: Colors.white,
    ),
    onPressed: _secondsRemaining > 0
        ? null
        : () async {
            await widget.authProvider.deleteAccount();
            if (context.mounted) {
              Navigator.popUntil(context, (route) => route.isFirst);
            }
          },
    child: Text(
      _secondsRemaining > 0
          ? 'Conferma cancellazione (attendi $_secondsRemaining secondi)'
          : 'Conferma cancellazione definitiva (ora attivo)',
      style: const TextStyle(color: Colors.white, fontWeight: FontWeight.bold),
    ),
  ),
),
```

### 2. Medium Severity

#### [MED-01] Missing Header Semantics on Settings Section Titles
- **File**: `d:\Feditok\lib\screens\home\profile\settings_screen.dart`
- **Line(s)**: 116–128
- **WCAG Guideline**: WCAG 1.3.1 Info and Relationships (Level A), WCAG 2.4.6 Headings and Labels (Level AA)
- **Defect**: Section titles ('Accesso', 'Privacy', 'Memoria', 'Danger Zone') generated by `_buildSectionHeader` are plain `Text` widgets without `Semantics(header: true)`. Screen reader users cannot use heading navigation shortcuts (such as the "H" key or rotor) to jump quickly between settings categories.
- **Code Fix**:
```dart
Widget _buildSectionHeader(BuildContext context, String title, {bool isDanger = false}) {
  return Semantics(
    header: true,
    child: Padding(
      padding: const EdgeInsets.only(left: 16, right: 16, top: 16, bottom: 8),
      child: Text(
        title,
        style: TextStyle(
          fontSize: 14,
          fontWeight: FontWeight.bold,
          color: isDanger ? Colors.redAccent : Theme.of(context).colorScheme.primary,
        ),
      ),
    ),
  );
}
```

#### [MED-02] Missing Accessible Dismiss Actions in Bottom Sheet Modals
- **File**: `d:\Feditok\lib\screens\home\profile\settings_screen.dart`
- **Line(s)**: 225–244, 246–278
- **WCAG Guideline**: WCAG 2.1.1 Keyboard (Level A), WCAG 2.4.3 Focus Order (Level A)
- **Defect**: Bottom sheets displayed for "Visualizza Video Online" and "Gestione Video Salvati in Locale" lack an explicit "Chiudi" action button or semantic dismissal handle. Keyboard and screen reader users may find it difficult to exit the modal without a hardware back gesture.
- **Code Fix**:
```dart
// Include a header bar with an explicit close button in the bottom sheet:
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Semantics(
      header: true,
      child: const Text('Memoria Locale', style: TextStyle(fontWeight: FontWeight.bold, fontSize: 16)),
    ),
    IconButton(
      icon: const Icon(Icons.close),
      tooltip: 'Chiudi gestione memoria',
      onPressed: () => Navigator.pop(context),
    ),
  ],
),
```

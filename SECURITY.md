# Security Policy

## Supported Versions

The supported version is the latest one, we usually keep the compatibility the same, so its
very unlikely that you will see in the repo a warning like 

"THE APP WILL NOT BE COMPATIBLE FOR ANDROID x OR BELOW! UPGRADE YOUR PHONE IF IT DOESNT MEET THIS REQUIREMENT"

Here's the table for the minimum requirements

| System  | Minimum requirement  |
----------|----------------------|
| Android | Android 5.0          |
| iPhone  | iOS 15               |
| iPad    | iOS 15               |
| Mac     | iOS 12               |
| Windows | Windows 10           |

## Reporting a Vulnerability

If you find a security vulnerability (like SQL injection, keys, ecc.) go to the security tab and REPORT IT AS SOON AS POSSIBLE
An human will handle the report.

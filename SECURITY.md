# Security Policy

## Supported Versions

The supported version is the latest one, we usually keep the compatibility the same, so its
very unlikely that you will see in the repo a warning like 

"THE APP WILL NOT BE COMPATIBLE FOR ANDROID x OR BELOW! UPGRADE YOUR PHONE IF IT DOESNT MEET THIS REQUIREMENT"

Here's the table for the minimum requirements

| System  | Minimum requirement  |
----------|----------------------|
| Android | Android 5.0          |
| iPhone  | iOS 15               |
| iPad    | iOS 15               |
| Mac     | iOS 12               |
| Windows | Windows 10           |

## Reporting a Vulnerability

If you find a security vulnerability (like SQL injection, keys, ecc.) create an issue PROMPTLY with the tag SECURITY VULNERABILITY.
It will automaticly be assigned and review first by AI to check if it is real (AI will NOT close the issue immidiatly) then by human.

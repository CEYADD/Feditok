# Feditok

[![Flutter Error Control](https://github.com/PiedinoTimido/Feditok/actions/workflows/Flutter%20Error%20Controll.yml/badge.svg)](https://github.com/PiedinoTimido/Feditok/actions)
[![License: GPL-3.0](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

Un'applicazione Flutter per replicare l'esperienza di TikTok, ma decentralizzata nel **Fediverso** (ActivityPub)!

---

## 🚀 Caratteristiche Principali
- 📱 **Feed Video Verticale:** Scorrimento fluido di contenuti video verticali.
- 🌐 **Autenticazione ActivityPub Dinamica:** Accesso e sincronizzazione profilo direttamente dalla tua istanza Mastodon o compatibile.
- 🔐 **Supabase Backend Sicuro:** Gestione del database con Row Level Security (RLS) avanzata e storage bucket protetti.
- ❤️ **Interazioni Social:** Like, commenti e gestione delle amicizie.
- ♿ **Accessibilità WCAG:** Conforme agli standard di accessibilità e screen reader.
